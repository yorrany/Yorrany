# Plano de Implementação: CRUD Inline do Disney+ Kids na Home Page

Este plano descreve como estender o catálogo de streaming **Disney+ Kids** na Home Page para que usuários administradores possam gerenciar (criar, visualizar, editar e excluir) os conteúdos diretamente na interface, sem precisar navegar até o painel administrativo clássico.

## User Review Required

> [!NOTE]
> Esta funcionalidade só será exibida e ativada para o usuário administrador autenticado (email: `yorranymb@gmail.com`). Para usuários comuns ou visitantes anônimos, a interface da Home continuará idêntica e otimizada apenas para visualização.

## Proposed Changes

### Backend (Rotas e API)

#### [MODIFY] [routes.rb](file:///var/www/app/config/routes.rb)
* Habilitar as rotas `:create`, `:update` e `:destroy` no namespace `:api` para o recurso `:disney_kids_contents`.

#### [MODIFY] [disney_kids_contents_controller.rb](file:///var/www/app/app/controllers/api/disney_kids_contents_controller.rb)
* Adicionar verificação de autenticação de administrador (`current_user&.admin?`).
* Implementar ações de CRUD:
  * `create`: Cria um novo registro de `DisneyKidsContent` e aceita anexo de imagem de thumbnail.
  * `update`: Atualiza um registro existente.
  * `destroy`: Remove um registro.

---

### Frontend (Visualização e Interação)

#### [MODIFY] [_disney_kids_streaming_section.html.erb](file:///var/www/app/app/views/home/_disney_kids_streaming_section.html.erb)
* Passar o status do administrador para o controller do Stimulus:
  `data-disney-kids-streaming-admin-value="<%= current_user&.admin? ? 'true' : 'false' %>"`
* Adicionar a estrutura HTML do **Modal de Gerenciamento CRUD** (com design premium, glassmorphism e inputs elegantes com foco iluminado).
* Adicionar um componente de **Toast de Notificação** dinâmico e sutil para feedbacks imediatos de sucesso/erro.

#### [MODIFY] [disney_kids_streaming_controller.js](file:///var/www/app/app/javascript/controllers/disney_kids_streaming_controller.js)
* Declarar `adminValue` e novos targets do Stimulus (`crudModal`, `crudForm`, `toast`, etc.).
* Atualizar o renderizador do catálogo (`renderCatalog`):
  * Se `adminValue` for `true`, injetar um card "Adicionar Novo Filme" no início do grid/carrossel.
  * Adicionar botões de ação flutuantes (Editar e Excluir) no topo de cada card de filme existente, ativados sob hover.
* Implementar métodos de manipulação CRUD:
  * `openCreateModal()`: Abre o formulário limpo para inserção de um novo registro.
  * `openEditModal(event)`: Busca dados do filme selecionado e preenche o formulário para edição.
  * `submitCrudForm(event)`: Faz a submissão assíncrona do formulário usando `fetch` (suportando upload direto de imagens ou inserção de URL) e enviando os tokens CSRF necessários.
  * `deleteContent(event)`: Dispara confirmação e envia requisição `DELETE` para apagar o conteúdo.
  * `showToast(message, type)`: Exibe alertas flutuantes altamente polidos na tela.
  * Recarregar dinamicamente o catálogo na tela sem recarregar a página física pós-sucesso.

---

## Verification Plan

### Automated Tests
* Nossos endpoints de API serão verificados garantindo que:
  * Usuários não-autenticados ou não-admins recebam erro `401 Unauthorized` ou `403 Forbidden` ao tentar POST/PATCH/DELETE.
  * Usuários administradores consigam realizar o CRUD completo com respostas em formato JSON válidas.

### Manual Verification
1. Fazer login como o usuário administrador (`yorranymb@gmail.com`).
2. Acessar a Home Page e rolar até a seção do Disney+.
3. Verificar a presença do card "+ Adicionar Novo Filme" e dos ícones de editar/excluir nos cards de filmes.
4. Criar um novo filme enviando tanto uma imagem local quanto inserindo uma URL externa.
5. Editar um filme existente (ex: mudar o título e a descrição) e salvar.
6. Excluir um filme e observar a animação de remoção imediata da listagem.
7. Verificar se o modal de trailer continua funcionando normalmente ao clicar no centro dos cards.
