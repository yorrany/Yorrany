# Deploy Automático

Sempre que você (a IA) fizer ajustes de código, correções de bugs ou qualquer alteração nos arquivos deste projeto, você **DEVE** sugerir ou pedir autorização ao usuário para executar o script de deploy ao final. Você deve executar o script `./deploy.sh` apenas após a confirmação.

- **Comando a ser executado:** `./deploy.sh` (a partir da raiz do projeto).
- **Momento de execução:** Imediatamente após a conclusão das edições e testes, com consentimento prévio do usuário.
